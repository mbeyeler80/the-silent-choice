# Font usage — prototype v0.1

Do not bundle font binaries in this asset pack.

Use these open-source families through Expo Google Fonts:

- Narrative/UI: `Raleway` via `@expo-google-fonts/raleway`
- System/terminal: `Space Mono` via `@expo-google-fonts/space-mono`

Suggested defaults:
- Narrative body: Raleway 400
- Choices: Raleway 500
- System/terminal: Space Mono 400
- System warnings: Space Mono 400, uppercase

Fallbacks: system sans-serif for narrative, system monospace for terminal text.
